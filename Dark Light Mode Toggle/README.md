# Premium Dark & Light Mode Toggle 🌓

A highly optimized, hardware-accelerated glassmorphic toggle button for switching between Dark and Light mode themes. Designed with Apple-level motion fluidity, custom cubic-bezier curves, and seamless texture morphing.

## ✨ Features

- **60 FPS Fluid Transitions**: Uses CSS custom properties to animate positions with `transform: translate3d()` and custom pseudo-elements instead of layout-altering properties (`left`, `background-image`).
- **Seamless Icon Morphing**: The sun and moon icons spin and scale down to `0` at the midpoint of the slide, swap seamlessly, and scale back up.
- **Tactile Hover & Active Interactions**: Supports minor spring-based expansion (+8%) on mouse hover and compression (-5%) on click/active press.
- **Fully Responsive**: Adapts seamlessly to Mobile, Tablet, and Desktop viewports.
- **Spam Protection**: Prevents animation stuttering by blocking rapid clicking.

## 🛠️ Technologies Used

- **HTML5** (Semantic structure)
- **CSS3** (Custom cubic-bezier curves, glassmorphism, CSS variables, and pseudo-element cross-fades)
- **JavaScript** (Event orchestration & state management)
